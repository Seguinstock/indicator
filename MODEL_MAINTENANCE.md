# Stock Indicator — règle de maintenance du modèle

`fonctionnement.html` est la documentation de référence du modèle actif.

À chaque modification qui touche une formule, un poids, un seuil, un indicateur, une table de points, une règle de classement ACHAT/VENTE, une logique de filtre ou une méthode de calcul, **mettre à jour `fonctionnement.html` dans le même changement** afin que l’explication reste fidèle au code réellement exécuté.

Si un calcul est temporaire, expérimental ou conservé uniquement comme diagnostic, l’indiquer explicitement dans la page au lieu de le présenter comme une règle de classement active.
